# Northstar Institute

A modern higher-education marketing website for a forward-looking institute, built with React, TypeScript, Vite, and Tailwind.

## Included pages

- Home
- Programmes and programme detail pages
- Admissions information
- Faculty directory
- About and campus life
- Events and news
- Contact form

## Local development

Requirements:
- Node.js 18+
- npm

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Stack

- React
- TypeScript
- Vite
- TanStack Router
- Tailwind CSS
